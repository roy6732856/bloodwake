# BLOODWAKE｜血月獵場

**[直接線上玩](https://bloodwake.vitas880709.workers.dev)** · [Public GitHub](https://github.com/roy6732856/bloodwake)

可直接玩的 3D 俯視生存射擊 Roguelite 原型。Three.js 真實 3D 場景，繁體中文介面，單局 5 分鐘，離線本機可運行。

## 0.6 長夜遠征與主角模型重製

- **5 名獵人**：新增熔火鍊金師（銀彈灼燒、四秒焰池）與霜衛騎士（35 點可再生護盾、新星回盾），各有三種染色、概念肖像與原創合成音樂。
- **主角模型重製**：五名角色沿用同一套重建的成人比例、髖部步行關節、彎肘持槍手勢、分指手套、平底戰靴、曲面胸甲、立體面甲、領片與長衣。角色有兜帽／冠冕／試劑背架／臂盾等裝備差異；大廳與實戰使用同一模型。
- **3 張地圖**：墓園、熔爐工坊、冰晶迴廊。熔流有兩秒預警與三處安全橋面；寒霜區週期啟動、區內移速降低。新地圖包含獨立碰撞布局與地形視覺。
- **3 種任務**：自由生存、首領追獵、封印儀式。主頁預設首領追獵：40／120／200 秒預告三名首領，須全部擊倒並存活至五分鐘。儀式須依序清場、站入祭壇八秒完成三座封印，再活到黎明。
- 任務與地圖自由搭配。追獵殘魂 +25%、儀式 +30%，與契約及試煉倍率相乘。新任務加入有預警的混合敵人；滿場時可移除遠距普通敵人，為目標預留名額，不給擊殺獎勵。
- 最近六場戰局保存角色、地圖與任務，沿用 D1 JSON 資料；舊 0.3／0.5 客戶端不會抹掉已有紀錄的新版欄位。沒有新增執行期套件或付費 AI 推論。
- 模型是程式建構的風格化 3D，概念肖像與地圖圖卡是生成插畫，並非遊戲截圖或同等細節的雕刻模型。

驗證：24 項 Node 測試、33 項瀏覽器檢查、12 項本機 Workers + D1 整合檢查。另以零傳承存檔、正常生命值、固定種子、黑棘弩與腳本走位測試 12 場，11 勝 1 敗；這是流程與策略探測，不是人類勝率或完成平衡的證據。首領仍共用典獄長技能，長期成長與熟手難度有待後續擴充。

## 0.5 獵人聖所

- 主頁直接選擇三名獵人，查看各自能力、概念肖像與可拖曳旋轉的即時 3D 模型；「踏入獵場」直接出發，「配裝與試煉」保留完整開局選項。
- 三種不同輪廓：灰燼層疊護肩、緋影兜帽、使徒冠冕與月環。實戰沿用同一套角色模型，增加金屬反射、生成的微刮痕材質、布料起伏、發光飾件。
- 每名獵人有三種染色；外觀保存在此瀏覽器，與戰鬥能力無關。跨裝置 D1 仍同步成長和戰局記憶，染色偏好不送到雲端。
- 可在祭壇試映銀彈、緋影殘像與新星外觀。這是視覺預覽，不額外授予新技能或變更既有傷害規則。
- 三首原創 Web Audio 合成主題：灰燼聖歌、紫夜疾行、月蝕祈禱。需點擊啟用，含音量、播放／暫停、真實頻譜電平；切換角色換曲，背景分頁暫停排程，戰鬥 HUD 可獨立控制音樂。
- 新增生成的教堂背景、角色肖像與金屬材質。主角為即時風格化 3D，肖像為概念美術，並非相同細節級別的模型掃描。
- 不新增執行階段套件或外部音樂／模型 API，不需要 D1 migration。

驗證：19 個 Node 測試、26 個真實瀏覽器整合檢查、11 個本機 Workers + D1 檢查。瀏覽器包含選角染色進入戰鬥、角色切換、特效、旋轉、音樂節點回收和三條加速完整戰局。

## 0.4 血月意志

- 局內節奏導演：根據生命比例、近期受傷、附近敵人與清怪速度切換「窺視／獵潮／餘息」。敵人出生速率限制在原本的 65%～118%，既有敵人血量、傷害與玩家武器能力不變。低血量餘息最多每 60 秒提供一枚恢復結晶。
- 可選試煉：「獵殺印記」以 2.5 秒金色裂隙預告包抄，保留逃生方向，殘魂 +20%；「星蝕試煉」追加三輪有紅圈預警的星雨，殘魂 +25%。試煉與契約收益相乘；Boss 在場或餘息期間會延後新一輪試煉。
- 跨局記憶：保留最近 6 局的摘要與「太輕鬆／剛剛好／太挫折」回饋，推薦兵器和試煉。推薦不自動替玩家選擇。主動結束的戰局不計入分析。
- 經典模式：關閉動態節奏，仍可自由選擇試煉。
- 本版是可解釋的規則導演與個人戰局推薦，尚未接入生成式模型、訓練模型或全玩家推薦學習。不呼叫 Workers AI，不增加模型推論費用。
- 血月記憶沿用現有 D1 JSON 存檔，不需資料表遷移；舊 0.3 客戶端上傳時仍會保留新記憶。

## 啟動

安裝 Node.js 後，在本資料夾執行 `node server.mjs`，開啟 http://127.0.0.1:4173 。遊戲執行所需的 Three.js 與圖片都包含於專案，本機遊玩不需要 npm install、API 金鑰或遊戲帳號。若 4173 已被占用，可設定 PORT 環境變數。

Windows 亦可雙擊 `啟動遊戲.cmd`。請從伺服器網址開啟，直接雙擊 index.html 會受 ES module 的瀏覽器限制。

## 操作與玩法

- WASD／方向鍵移動；滑鼠瞄準，按住左鍵射擊。
- Space 衝刺（短暫無敵），E 新星（範圍傷害與擊退）。
- Q 開啟附近聖匣；觸控可點畫面上的開啟按鈕。
- F 切換自動射擊，瞄準仍由滑鼠控制。
- Esc／P 暫停，切換視窗也會自動暫停。
- 1／2／3 選擇升級。觸控可用左右虛擬搖桿與技能按鈕。
- 拾取青色靈魂升級；紅色結晶補血。墓碑會擋住移動與銀彈。
- 五種普通敵人：行屍、血蝠、重甲屍、施法者、衝撞者；自由生存／儀式每分鐘召喚典獄長（同時最多一名）；追獵依任務時程出現標記目標。
- 十四種隨機局內強化。存活至 05:00 並完成所選任務獲勝，死亡或主動結束也可獲得已賺取的殘魂。
- 每 8 次擊殺 +1 殘魂，每存活 20 秒 +1，生還額外 +20。主選單傳承商店可購買三類永久強化，各 5 階。
- 進度儲存在 localStorage `bloodwake.save.v1`，只屬於同一瀏覽器與網址；線上版可啟用 D1 雲端同步。

## 技術與素材

原生 ES modules + Three.js 0.180.0（vendor 目錄，MIT）。實作參照官方 [OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html) 與 [Raycaster](https://threejs.org/docs/pages/Raycaster.html) 文件。無外部執行期 CDN。Web Audio 合成射擊、拾取、升級、受傷音效。

`src/game.js`：固定步長戰鬥、碰撞與敵潮。`src/models.js`：3D 模型與場景。`src/progression.js`：升級、經濟、存檔驗證。`src/main.js`：HUD、選單、觸控操作。

`src/content.js`：角色／武器／契約／進化／印記資料。`src/encounters.js`：事件、聖匣、遠程攻擊、飛刃與道具。`src/feedback.js`：命中、傷害文字與特效。`src/loadout-ui.js`：配裝和圖鑑介面。

Image Gen 生成的概念：`design/concept.png`；石地材質：`public/assets/slate.png`；血月選單背景：`public/assets/bloodmoon.png`。提示詞／設計說明見 design 目錄。角色與障礙物採實際 low-poly 模型，與概念圖的細節程度有意識地區分，以保留真 3D 和瀏覽器效能。

0.2 新增透明 VFX：`public/assets/impact.png` 與 `public/assets/arcane-ring.png`。提示詞見 `design/fx-assets.md`。AI 圖像與程式生成的 3D 模型是不同素材，不把概念圖視為實機截圖。

## 驗證

`node --test tests/*.test.mjs`：19 項規則測試，涵蓋永久強化、損壞存檔、隨機選項、27 種配裝、進化門檻、成就重複領取與契約獎勵。

開啟 `/tests/browser.html`，按 Run integration checks 執行 23 項瀏覽器整合測試。包含三把武器各一次加速五分鐘內容循環；長局測試使用高生命值避免提早死亡，驗證的是穩定性而非難度平衡。測試結束會還原原本存檔。正式遊戲網址不要加 `?qa`；這個參數只供本機測試存取遊戲狀態。

0.1 的美術比對記錄保留於 `design/QA.md`，其中截圖代表初版；0.2 的玩法以本 README 和可運行測試為準。

此版本是單一競技場原型；尚未包含多人連線、多張地圖、完整角色動畫素材。

## 線上版與雲端存檔（0.3）

Cloudflare Workers Static Assets 提供遊戲；Worker API + D1 保存每位玩家的殘魂、永久強化、印記、遊玩次數與最佳時間。局內位置／敵人狀態不存檔；這是單人遊戲，尚未包含即時多人對戰。

主選單 → 雲端存檔 → 啟用雲端，即可把原本進度上傳。顯示並私人保存復原碼；換裝置輸入復原碼 → 查找 → 確認紀錄 → 套用。復原碼是存取憑證，遺失後無法從帳號或信箱重設；D1 只保留 SHA-256 雜湊，不保存原碼。這台裝置的復原碼留在 localStorage，不會放入網址、Git 或靜態檔。

每局結算、傳承購買後合併同步；斷線時先保留本機，連線恢復或按「立即同步」後重試。CAS 版本檢查阻止不同裝置互相靜默覆蓋；有衝突時選擇保留本機或雲端。替換前會保留一份本機備份。若關閉頁面前尚未同步，下次開啟仍會補傳。

從本機版搬到公開網址：先「匯出本機存檔」，在公開網址「匯入存檔」，再啟用雲端。不同網址有不同的瀏覽器儲存空間。

部署步驟、免費額度與資料格式見 [DEPLOY.md](DEPLOY.md)。

0.4 另有 `node tests/cloud-integration.mjs` 的 11 項本機 D1 整合測試，包含六局記憶往返、舊客戶端保存與衝突處理。先啟動 `npm run dev:cloud`。
