# Bloodwake design system

Reference: concept.png generated with built-in Image Gen. Final prompt: complete 3D top-down gothic graveyard survival-shooter gameplay screen, charcoal slate, ivory serif BLOODWAKE, Traditional Chinese controls, red health, turquoise XP, three outlined skill buttons at bottom center, timer top center, health lower left, kills lower right. A separate built-in texture prompt generated seamless dark blue-gray hand-hewn slate paving without perspective or objects (public/assets/slate.png).

Tokens: background #080d13; ivory #e9dcc1; muted #a39b8b; gold #b89c6b; turquoise #51d8d2; health #b52e42. Georgia serif branding/timer/numerals; Microsoft JhengHei/Segoe UI controls. Square fine-border buttons; no rounded panels. Full-bleed canvas, corner HUD, center timer and skill rail. Top XP 3px. 34px desktop gutters, 12–17px mobile gutters.

Required states: start menu, live play, pause, three-choice level up, legacy shop, defeat/victory. Their functional copy extends the gameplay concept deliberately. Layout keeps these controls code-native.

Intentional art adaptation: user explicitly requests real 3D. Characters, graves, columns, fences, bullets and crystals are low-poly meshes, with animated limbs, lights and shadows rather than generated 2D sprite replacements. Generated slate is a world material. Bloodmoon is menu background art. The reference's cinematic distant skyline is reserved for the menu; gameplay uses a readable moving orthographic camera above the actual arena. Model detail is intentionally stylized for browser performance, not a claim of photorealistic screenshot parity.
